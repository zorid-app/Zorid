# Typed visual filter campaign

Source-authored; actual execution remains required. The 65 explicit cases use
five ordinary notes, a nonmember link target and one Base. They cover String
comparisons and six methods/inverses; List exact equality versus variadic
membership; mixed `[1,true,"1",null]` members; numeric comparisons/null/empty;
real checkbox values; all six date and datetime comparisons with quoted ISO
String operands; no-RHS empty predicates; all eight existing File conditions.
The normal Add filter action is retained: its second local row is completed,
and the default unused blank must be excluded from the saved expression.

Every case requires exact ordered row membership, the complete independently
expected Base configuration, exact reopened property/operator and scalar
type/value or ordered chips, then normal removal and all-five membership.
Reopening preserves bytes. Four list cases additionally remove/re-add the last
item through ordinary controls and require both intermediate and restored exact
expressions. This verifies retained primitive types where Number1 and String"1"
share a visible chip label, and pins array versus variadic argument structure.
The zero-result String case must retain its captured String operator catalog;
there is no first-returned-row type inference. Clear value explicitly authors
comparison Null, distinct from an incomplete blank and from text/list empty.
It may reopen as the existing set/unset compatibility presentation; exact
source and membership remain mandatory.

Separate loaded views retain an unsupported advanced expression, an offset
timestamp RHS and a single List argument (distinct from variadic arguments).
They require unchanged exact source and independent membership before/after a
normal application restart. Every note, registry and target file must retain
its complete original bytes. Note values and expectations are handwritten;
no product parser, evaluator or serializer produces expected results.

The typed toolbar controls follow the audited descriptor/widget contract in
`/private/tmp/zorid-bases-filter-type-audit-20261022/matrix.md`. That audit is
static shipped-artifact evidence; this campaign does not establish reference
runtime, visual parity, mobile, sync or performance acceptance. Known supported
operators must reopen structurally; unsupported source is preserved without
guessing a replacement. Native date/datetime input uses trusted UI input and
strict field readback. A platform input failure stops the campaign; it is never
replaced by DOM assignment or a `date()` expression.
