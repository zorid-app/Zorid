# Reference evidence

Historical audits of reference-app behavior, UX and interaction details. These
files are evidence for specific inspected artifacts, not current Zorid architecture
or blanket exact-parity requirements. The current exception is the explicitly
requested inspected Obsidian local save/recovery behavior recorded in architecture decisions.

Start at the [architecture manual](../architecture/README.md) for the application
itself. Some source-linked reference pages retain their original root paths.
