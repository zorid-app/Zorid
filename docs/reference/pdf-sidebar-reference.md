`src/ui/pdf-sidebar.ts` is an original component using public document APIs from separately acquired official PDF.js 5.3.31: `getOutline`, `getDestination`, `getPageIndex`, `getPage`, page viewport and render tasks. It supplies functional thumbnails, destination navigation, collapsible outline, page-label flairs, current-section reveal, and keyboard movement through visible outline entries. The viewer adapter owns toolbar/menu integration, page/rotation synchronization, overlay versus shifted layout, find-bar inset and disposal. Closing the PDF destroys sidebar work before destroying the document worker.

Performance choices are explicit deviations from unverified reference internals: thumbnails are virtualized to at most 12 mounted cells/canvases, with one active render; offscreen canvases are zeroed, and each thumbnail raster is capped at 262,144 pixels and 4,096 pixels per dimension at at most 2x device scale. Render tasks are cancelled when closed, rotated, destroyed, or evicted. Late non-cancellable page acquisition/outline metadata cannot attach to a destroyed view. Estimated row heights are corrected as pages render; mixed-aspect PDFs may change scrollbar geometry until visited. Outline page destinations resolve lazily for visible rows and on reveal, with per-row cached promises. Reveal can walk all outline records sequentially; cancellation stops further requests. The outline DOM is not virtualized.

Verification includes a 10,000-page fake document proving bounded thumbnail cells/canvases and page requests, cancellation during render and page acquisition, late outline results, retained callbacks after destruction, branch navigation and labels, missing-outline availability, reveal ancestry, and failure retry bounds. An original generated PDF is also parsed by actual official PDF.js: sidebar painting is checked for red pixels and an actual outline indirect destination is resolved to its page. Existing PDF-view lifecycle and menu tests remain in the validation set. jsdom cannot validate scroll metrics, animation, pointer geometry or native focus; root owns Electron and mobile verification.

Remaining: standalone resize and saved sidebar state; exact animation and tree selection/keyboard parity; thumbnail/outline context-menu wiring to host link/clipboard capabilities; upstream page-canvas reuse; optional-content visibility synchronization; remote/action-only outline entries; same-page destination ties; native large-document scroll/zoom performance; touch gestures; accessibility comparison with the reference. These are real controls and rendering, not placeholders, but full sidebar parity is not claimed.

Independent review found and corrected two boundary defects: a thumbnail evicted during rendering incorrectly surfaced expected cancellation through the error callback, and an area-only scale limit could exceed its raster budget after forcing a tiny dimension to one pixel. Evicted work now finishes quietly, while final integer canvas dimensions respect both the area budget and a 4,096-pixel per-dimension cap. Regressions exercise scrolling away from an active render and an extreme 1:100,000,000 page aspect ratio. Final focused PDF/sidebar/menu/embed/attachment suite: 61 passing tests; TypeScript and diff checks pass. Production webpack build passes with existing asset-size/performance warnings.
