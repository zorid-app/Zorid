# Implementation and verification history

Read their source revision, date and limitations; an old report is not a current
architecture description or proof that a newer composition passed.

Use the [architecture manual](../architecture/README.md) for current boundaries and
the [execution checkpoint](../deferred-product-roadmap.md) for ownership. Active
contracts/plans and source-addressed documents retain their existing root paths.
[Relocations](relocations.json) maps old root report paths to their new locations.
